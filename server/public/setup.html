1. Administrator

Sign in as the administrator created on first start, then shape the warehouse here. You can run this again later.

Where this warehouse is

Billing days, seasons, rate cards and the journal use local midnight here, including daylight saving.

2. Warehouse type

A preset turns features on or off and suggests a location plan. It does not delete stock you already have.

3. Category features

Temperature, lot and expiry, FEFO, and high-value PAL/MASTER plates are optional.

What do you use?

Leave out what this place does not need; its screens disappear. A preset fills this in, and you can change it any time.

4. Your locations

A few questions about the building. Type what you call the first one and the rest follow: 01 gives 01, 02, 03; A gives A, B, C; Shelf 1 gives Shelf1, Shelf2; or write every name, split by commas.

5. Extra places

Advanced: write the ranges yourself

Cell, then aisle, bay, position and height. Each level is numbers, letters, letter+number or words.

Live preview

Choose an example or edit the ranges.

Virtual locations

Consolidation and staging are not physical slots. conso00 is the usual consolidation name.

6. Finish

Saving marks the wizard complete. Open it again from the administrator settings whenever the building changes.

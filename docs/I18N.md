# Languages

English is the default. Dutch (`nl`) is the second language. A person's language is kept on their account. When they have not chosen one, the warehouse language is used. When that is empty too, the screens stay in English.

Numbers, dates and money follow the language. Dates and times use the warehouse timezone, the same clock as billing and the journal.

The sentences live in `locales/en.js` and `locales/nl.js`. The key is the English sentence. `src/i18n.js` looks a sentence up. Screens that redraw replace a text node when its whole text is one of those sentences.

## Add a language

1. Copy `locales/en.js` to `locales/<code>.js`, using the two-letter code (`fr`, `de`).
2. Translate every value. Leave the keys as they are. Do not leave a value empty.
3. Add the code to `languages()` in `src/i18n.js`, and to the language lists on the sign-in header and the warehouse settings.
4. Serve the file from `server/index.js` next to `/locales/en.js` and `/locales/nl.js`.
5. Run `npm test`. The test in `test/i18n.test.js` fails when a key from English is missing or blank in Dutch. Do the same check for the new file before you ship it.

A terminal that cannot show UTF-8 uses `fold()` in `src/i18n.js`, which strips accents so the words still read.

Labels, the printable invoice and CSV headers use the same catalogs. CSV headers stay English unless the warehouse language is not English.
